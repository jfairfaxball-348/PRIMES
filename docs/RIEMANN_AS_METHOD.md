# Riemann as Method

This document uses the historical scale of Riemann's leap as a design lesson. It does not make the Riemann zeta function or the Riemann Hypothesis a target.

## Thought experiment

Suppose the modern conceptual machinery surrounding primes were absent. What sequence of research moves could lead from raw primes to a new structural theory?

The important lesson is not the final object. It is the sequence of compressions.

## 1. Count before explaining

Start with exact objects and exact counting functions.

Measure:

- how many primes occur up to a scale;
- how primes occupy local windows;
- how local configurations change with the scale;
- where simple baselines fail.

Do not demand a grand theory at the first plot.

## 2. Promote the residual

When a first-order rule captures most of the behaviour, the discrepancy becomes a new mathematical object.

For any baseline `B(x)`, define and inspect an exact or explicitly approximate residual `R(x)=A(x)-B(x)`.

Ask:

- Does the sign have structure?
- Do extrema recur in a scaled coordinate?
- Are excursions locally asymmetric?
- Do different baselines expose the same events?
- Is there a transform in which the residual simplifies?

The residual may contain more discovery information than the leading trend.

## 3. Search for a representation that makes arithmetic additive, geometric, or finite

A major conceptual leap often comes from changing representation.

PRIMES should systematically try representations in which the same prime data becomes:

- a word;
- a graph;
- a point configuration;
- a transition system;
- a hierarchy across scales;
- a transform;
- a family of finite local objects.

A useful representation is one that turns many unrelated-looking observations into one structural constraint.

## 4. Look for dual descriptions

Deep structure often appears when one object can be computed in two qualitatively different ways.

For each promising invariant ask:

> Is there another exact representation of the same quantity?

Examples of duality styles include local/global, index/value, additive/multiplicative, spatial/spectral, combinatorial/analytic, or direct/transform-domain.

The project does not preselect which duality should win.

## 5. Invent the missing object

If several anomalies move together, do not immediately fit a more complicated curve. Ask whether there is a hidden object whose simpler behaviour would explain all of them.

A candidate new object earns attention when it:

- compresses multiple observations;
- predicts unseen behaviour;
- has an exact definition;
- suggests theorems;
- connects previously separate representations.

## 6. Seek obstruction, not confirmation

Once a structural explanation is proposed, search for the configuration that should destroy it.

The fastest route to a real theorem is often learning the exact boundary of a false conjecture.

## 7. Translate computation into mathematics

A computational feature becomes mathematically valuable when it can be rewritten as:

- an identity;
- an inequality;
- a forbidden configuration;
- an extremal principle;
- a recurrence;
- an invariant;
- a limiting or density statement with explicit quantifiers.

## 8. Only then collide with history

After a candidate has independent internal life, perform the prior-art audit.

This ordering lets us learn what *we* would have needed to invent, while still respecting the fact that modern mathematics may already contain it.

## The standard to aim for

The goal is not to imitate a famous answer. It is to build a process capable of recognizing when raw arithmetic data is asking for a new language.
