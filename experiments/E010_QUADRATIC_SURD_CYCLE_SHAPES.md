## Exact quadratic-surd recurrence

For every x in A_B, define

a0 = isqrt(x),

where isqrt is exact integer square root. Because x is nonsquare, validate

a0^2 < x < (a0+1)^2.

Initialize the exact integer state

m_0 = 0,
d_0 = 1,
a_0 = a0.

For k = 0,1,2,... compute the next state exactly:

m_{k+1} = d_k * a_k - m_k

r_{k+1} = x - m_{k+1}^2

Require r_{k+1} > 0 and r_{k+1} divisible by d_k, then define

d_{k+1} = r_{k+1} / d_k

and require d_{k+1} > 0.

Define

a_{k+1} = floor((a0 + m_{k+1}) / d_{k+1})

using exact integer division, and validate the equivalent quotient bounds

a_{k+1} d_{k+1} <= a0 + m_{k+1}
< (a_{k+1}+1) d_{k+1}.

The period terminates at the first positive index ell for which the canonical terminal state is

(m_ell, d_ell, a_ell) = (a0, 1, 2*a0).

If a nonterminal (m,d) state repeats before this terminal state, execution fails closed for that anchor. No floating square root, floating continued fraction, approximation, tolerance, or fitted stopping rule is permitted.

The exact recurrence-state sequence and coefficient/denominator values are computation/validation objects only. They are not promotable signatures and must not be serialized per anchor.

## Frozen denominator-cycle primitive

For one anchor x, let the exact denominator cycle be

D(x) = (d_1,d_2,...,d_ell),

including the terminal denominator d_ell=1.

For each distinct positive denominator value v appearing in D(x), let

mu_x(v) = # { k in {1,...,ell} : d_k = v }.

Let

M(x) = max_v mu_x(v)

and for j=1,...,M(x) define

h_j(x) = # { distinct denominator values v : mu_x(v)=j }.

Define the canonical multiplicity profile

H(x) = (h_1(x), h_2(x), ..., h_{M(x)}(x)).

By construction h_{M(x)}(x)>0, so H(x) has no trailing zero entry.

The following exact identities are mandatory validation/control facts:

ell = sum_j j*h_j(x)

number of distinct denominators = sum_j h_j(x)

M(x) = max { j : h_j(x)>0 }.

They are deterministic consequences of the representation and are never promotion-eligible.
