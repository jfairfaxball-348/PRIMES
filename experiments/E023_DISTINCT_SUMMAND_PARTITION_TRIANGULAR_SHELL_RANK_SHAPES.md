## 1. Primitive: unordered additive decompositions into distinct positive summands

For each integer n>=0 let `\mathcal{Q}(n)` be the set of finite **unordered** subsets A of the positive integers with `sum(A)=n`. The empty subset uniquely represents zero. Set `q(n)=|\mathcal{Q}(n)|` and `q(n)=0` for n<0. This is a finite combinatorial object: the members are positive **summand magnitudes**, not positions, labelled atoms, vertices, permutations, generator symbols or linear tiling pieces. Each magnitude may appear at most once. In the formal-polynomial sense, `q(n)=[z^n] product_{j=1}^n(1+z^j)` (the empty product for n=0); this is a direct independent specification, not an empirical model.

Define the triangular threshold `T_k=k(k+1)//2`, with `T_0=0`. For each allowed anchor x>=1, uniquely choose the integer `k>=0` with `T_k<=x<T_{k+1}`, and let `r=x-T_k` (hence `0<=r<=k`). Here k is the **greatest possible cardinality** of a subset of distinct positive integers with sum at most x, because the least possible sum of k distinct positive summands is `T_k`. This first-principles threshold is not an E015 square shell or fitted band feature. Compute exactly `k=(isqrt(8*x+1)-1)//2`, then **independently verify** both bounding triangular inequalities using integer multiplication; use no floating point.

For the three predetermined successive additive budgets `r,r+1,r+2`, evaluate the three **exact** counts `q(r),q(r+1),q(r+2)`, and separately reduce each modulo the same `m=x+1` to canonical integers `v_i=q(r+i)%m` with `0<=v_i<m` for i=0,1,2. The modulus is set before labels. The sole feature **P1** is the three-entry *dense weak-rank word* `t(x)=(a_0,a_1,a_2)`, where `a_i` equals the number of **distinct** values among `v_0,v_1,v_2` that are **strictly below** `v_i`.
